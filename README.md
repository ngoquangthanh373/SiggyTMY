This is not just a chatbot but a fully immersive Discord modeled Web3 AI interface designed to help the community understand nomination laws and grind roles smoothly

## ✨ Key Features

* 🔮 **Discord Native Experience** Automatically parses and colors Discord roles like @Radiant Ritualist or @ritty
* ⚡ **Slash Commands** Type a forward slash to open a menu of quick commands like /rules and /leaderboard
* ❤️ **Interactive Reactions** Hover over messages to drop emoji reactions just like real Discord
* 💾 **Eternal Memory** Powered by Local Storage so your chat history survives page refreshes
* 🛡️ **Anti Spam Lock** Safely disables the input field while the AI generates text to prevent API rate limits
* 🐟 **Pate Rain Easter Egg** Discover hidden commands to trigger raining cat treats and soothing purrs
* ⌨️ **Hacker Typewriter** Smooth character by character text generation for that authentic cyberpunk feel
* 🔊 **Soundscapes** Immersive UI sounds that can be toggled on or off instantly

## 🚀 Core Slash Commands

* **/rules** Unveils the sacred Hierarchical Laws of Nomination
* **/leaderboard** Guides users to the exact channel to check ranks
* **/nomi** Drops the direct link to the rank channel
* **/pate** Triggers the legendary Pate Rain easter egg

* Frontend HTML CSS Vanilla JavaScript
